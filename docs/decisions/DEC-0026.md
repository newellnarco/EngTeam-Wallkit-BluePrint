# Three oversight dashboards on the wall; the DESIGN tab waits for its data contract

## Question

The wall showed execution (MAIN / STORIES / CREW / LEDGER / WAITING) but
none of the oversight the disciplines now produce: retrospectives had no
surface (are the roles learning? did last wave's process diffs work?), the
Warden's rulings had no surface (what is blocked, what was refused, is the
posture healthy?), and the documents of record had no review surface (which
SOP changed since the Patron last read it?). The Patron asked (2026-09-21)
whether dashboards for retros, security posture, SOP/standard reviewability
by leadership, and requirements/design should be added, built and used.

## Decision

1. **Three new tabs ship** — RETRO, POSTURE, DOCS — folded by
   `tools/wall/oversight.py` into `snapshot["oversight"]` from three new
   ledger events (`retro_held`, `warden_ruling`, `doc_reviewed`;
   EVENT_SCHEMA "Oversight"). One snapshot, so no tab can disagree with the
   ledger. Charter: `docs/WALL_DASHBOARDS.md`.
2. **The DOCS tab is the review loop, not a listing**: the
   `documents_of_record` registry is hashed every courier run; the ack
   (`doc_reviewed`) carries the sha it was reviewed AT, so an ack at a
   stale sha does not make a changed document current. changed-since-review
   and never-reviewed are hot counts, like WAITING.
3. **Honest empty states are part of the contract**: each tab's empty state
   names the mechanism that would emit its data; an empty POSTURE tab on a
   repo with in-scope arcs is called a finding on its face.
4. **The DESIGN tab is deliberately NOT built** until its data contract
   exists: arc metadata (design ref, trajectories, tier, data uses) is not
   in the item fold, and a tab scraping authored prose would paraphrase —
   the same risk that makes the Courier a script. Slice 2 starts at the
   authoring/event contract (`WALL_DASHBOARDS.md` §4).

## Why

Same law as the rest of the wall: a discipline without a surface decays
silently — the retro's growth ledger, the Warden's checkpoint presence and
the Patron's review duty all produce records, and records nobody can see
are records nobody keeps. The reconciliation precedent stands behind the
sha-carrying ack in particular: evidence over self-report (G0b) applied to
document review — "I read it" is a self-report; "I read it at sha X" is
checkable against the tree.

## Revisit if

- The oversight events stay unemitted for several waves while the tabs
  render empty — then the disciplines, not the dashboards, are the gap, and
  the retro should say so.
- The DESIGN tab's data contract lands — build slice 2 per the charter.
- A host needs the wall shared beyond localhost for leadership review — that
  is a serve-boundary decision (WALL_STANDARDS §2), not a tab change.
