# Leases are the invariant; worktrees are the recommended isolation for git-writing builders

## Question

The distributed standard mandates git-worktree isolation for any subagent
that writes git state. The kit's model is leased disjoint scopes over a
shared tree, with worktrees as the parallel extension.

## Decision (the Patron ruled, 2026-09-19)

**Leases remain the kit's invariant** — they are what is enforced at
dispatch regardless of checkout topology. **Worktrees are the recommended
isolation for builders that commit**, and **mandated where the host's own
standing rules already say so** (the reference deployment does). The lease
check does not change in either topology.

## Why

The lease is the safety property (no two writers on one surface); the
worktree is an implementation of it with extra isolation. Mandating the
implementation would outlaw the shared-tree mode the kit's own first waves
ran safely under leases.

The lease model is RECONCILIATION's own shared-tree lesson set (G1/G2/G4); this ruling keeps that record binding and grades worktrees as its recommended implementation.

## Revisit if

A measured shared-tree corruption occurs that a lease could not have
prevented but a worktree would have.
